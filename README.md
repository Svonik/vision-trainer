# Vision Trainer

Дихоптический тренажёр бинокулярного зрения для детей 4-12 лет с амблиопией
(«ленивый глаз») и супрессией (подавлением зрения одного глаза при
косоглазии). Приложение построено на анаглифных очках (красный/циановый) и
играх, в которых каждый глаз видит свою часть изображения — это стимулирует
совместную работу обоих глаз.

> **Внимание.** Данное приложение **не является заменой очной консультации
> врача**. Рекомендуется использовать **только под наблюдением
> офтальмолога**, который подбирает и контролирует параметры терапии. При
> возникновении двоения (диплопии), головной боли или дискомфорта —
> немедленно прекратите использование и обратитесь к врачу.

## Возрастные группы

- **4-7 лет** — короткие сессии (15 минут), упрощённые механики.
- **8-12 лет** — сессии длиннее (25 минут), больше игровых вариантов.

Возрастная группа задаётся при калибровке и определяет длительность сессии и
протокол терапии.

## Научная основа

Терапевтические параметры (контраст, длительность сессий, частота занятий и
т.д.) основаны на обзоре 20+ научных публикаций по дихоптической терапии
амблиопии и бинокулярной супрессии. Подробности, включая соответствие
конкретных параметров кода источникам, — в [SCIENCE.md](./SCIENCE.md).

Само приложение не проходило независимых клинических испытаний — упомянутые
исследования относятся к протоколам и методикам из литературы, а не к
Vision Trainer как программному продукту.

## Разработка

```bash
npm run dev-nolog    # Dev-сервер (не npm run dev — требует log.js)
npm run build-nolog  # Продакшн-сборка
npm test             # Unit-тесты (Vitest)
npm run test:watch   # Vitest в watch-режиме
npm run test:e2e     # E2E-тесты (Playwright)
```

Подробнее об архитектуре — в `CLAUDE.md` (локальный файл, не в git).

## Технологии

Phaser 3 (игровой движок) + React (UI) + Vite (сборка) + TypeScript.
